# Psalmist Playback Review updates

Signed application updates for the Windows reviewer. Open START HERE in the current USB kit to check before MuseScore starts. No reviewer GitHub account is needed.

This public feed contains application code only. Books, review answers, connection settings, credentials and the MuseScore runtime are excluded. The source repository is private.

The application verifies the pinned RSA signature and hashes before installing. Offline startup keeps the installed version. Older kits need the new full kit once to gain the updater. Runtime and bootstrap changes require a new full kit.
